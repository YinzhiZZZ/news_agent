OpenAI 开发了部署模拟（Deployment Simulation）方法，在模型发布前通过重放历史对话、以隐私保护方式用候选模型重新生成回应，从而评估模型在真实场景中的行为表现。该方法已在多个 GPT-5 系列思维模型部署中应用，改进了对不良行为发生率的预测，识别出传统评估未能发现的新型错误模式，相比传统合成评估能有效应对非极端风险（频率≥1/200,000）。这一方法通过使用生产环境真实分布而非人工选择的困难场景，显著提升了模型安全评估的准确性，将成为未来模型开发流程中的核心环节。
