企业级AI语音客服代理平台

作者：未署名
语音AI助手客户服务自动化大模型应用无代码AI平台多模态AI编排

柏林AI公司Parloa基于OpenAI的GPT-5.4等模型构建了AI Agent Management Platform (AMP)，将传统规则驱动的语音客服转变为自然语言定义的智能代理系统。该平台通过模型模拟、评估和生产部署的端到端管理，使企业业务专家无需编码即可构建、迭代和优化客服交互，在密集的客户服务场景中实现自动化——从密码重置到复杂多步骤请求的全覆盖。AMP采用模块化提示工程和LLM-as-a-judge评估机制，确保生产环境中的性能稳定性和延迟控制，标志着企业级AI代理从硬编码规则向自适应模型驱动范式的转变。

实时语音AI模型的新突破

作者：未署名
实时音频处理多语言翻译语音代理对话AIAPI能力扩展

OpenAI发布三款新的实时语音模型，包括GPT-Realtime-2、GPT-Realtime-Translate等，为开发者提供更自然、更智能的语音应用能力。GPT-Realtime-2在Big Bench Audio上的音频智能评分比前代提升15.2%，在Audio MultiChallenge上提升13.8%，支持实时推理、工具调用、错误恢复等复杂对话功能。GPT-Realtime-Translate支持超过70种输入语言和13种输出语言的实时翻译，已在Priceline、Deutsche Telekom等企业的客户服务和多语言交互场景中测试应用，标志着语音AI从简单语音识别向真正具备工作能力的智能语音助手演进。
