OpenAI模型破解离散几何难题

作者：未署名
数学AI应用组合几何单位距离问题AI推理能力开放问题求解

OpenAI开发的通用推理模型首次自主破解了Erdős在1946年提出的平面单位距离问题——这道近80年来困扰数学家的离散几何核心难题。该模型推翻了长期以来关于方形网格构造最优性的猜想，提供了多项式级改进的无限构造族，并引入了代数数论中的深层思想。这一突破由外部数学家团队验证，标志着AI首次自主解决数学子领域的重要开放问题，证明现代AI模型具备超越辅助工具的能力，能产生原创性的数学思想并完整执行复杂推理。
