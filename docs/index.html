GPT-5.5 Instant 的健康智能能力升级

作者：未署名
大语言模型医疗AI应用AI评估方法论模型安全性医患沟通辅助

OpenAI发布了GPT-5.5 Instant的健康智能改进成果，每周2.3亿用户使用ChatGPT获取健康咨询。该模型在紧急情况识别、上下文理解、不确定性表达等关键指标上已达到前沿思考模型水平，由全球医生网络主导的评估驱动。生产环境数据显示，过去两个月内健康回复的事实性问题率下降71%（基于每周数十亿条消息），医生对比评估中GPT-5.5 Instant的失败模式显著少于旧模型和人类医生。这标志着AI在医疗辅助领域的可用性和安全性取得重大突破，为大规模医疗应用奠定了基础。

AI助力罕见遗传病诊断

作者：未署名
医疗AI应用基因组测序深度推理模型罕见病诊断临床决策支持

波士顿儿童医院、哈佛大学和OpenAI合作使用OpenAI o3深度推理模型对376例既往未确诊病例进行重新分析，为18个诊断提供了证据支持，诊断阳性率达4.8%。该模型作为解释驱动的推理层，将患者临床特征、遗传变异、继承模式与科学文献相关联，生成专家可审查的假设而非直接诊断，突破了基因组测序无法诊断的瓶颈。研究表明AI辅助工作流程可将罕见病重新分析从耗时专家工作扩展为可规模化处理，标志着AI在精准医疗领域的实际突破。
